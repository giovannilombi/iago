# Updates

IAGO checks on its own whether there is a new version (Settings › General › Updates).
The notes of every update say **what changes** and, when needed, **why** it should be installed. Updates are of three kinds:
- **Regular:** install now, later, or skip the version.
- **Important:** not mandatory, and IAGO works as usual, but they cannot be skipped. The notes say why it is worth installing them soon.
- **Mandatory:** the notes say why. You have **2 days** to install them: IAGO's menu shows until when, and *Update now…*. After that IAGO starts no new recordings, transcriptions, summaries or suggestions until you update; just press *Update now* and IAGO reopens updated. The archive stays readable and a recording in progress is never interrupted.
- Every update is signed: IAGO installs only versions signed by the same author.

The notes for each version are on the releases page.

Automatic updates apply to IAGO installed from the **DMG**. A copy built from the source code (for those who develop IAGO) does not look for them: it is updated with git and a new build.
