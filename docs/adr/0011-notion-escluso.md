# ADR-0011 — Notion escluso

- Stato: accettato
- Data: 2026-10-11
- Riferimenti spec: sez. 17.11

## Contesto
È stata considerata un'integrazione con Notion come destinazione per trascrizioni e note.

## Decisione
Nessuna integrazione con Notion. L'esportazione verso strumenti di conoscenza avviene tramite file Markdown (export di riga/progetto) e lo specchio Obsidian locale (fase 2).

## Conseguenze
- Nessun servizio cloud di terze parti con accesso ai contenuti.
- Chi usa Notion può importare manualmente i Markdown esportati.
