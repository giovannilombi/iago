# ADR-0011 — Notion excluded

- Status: accepted
- Date: 2026-10-11
- Spec references: sec. 17.11

## Context
An integration with Notion as a destination for transcripts and notes was considered.

## Decision
No integration with Notion. Export to knowledge tools happens through Markdown files (row/project export) and the local Obsidian mirror (phase 2).

## Consequences
- No third-party cloud service with access to the contents.
- Those who use Notion can manually import the exported Markdown files.
