# ASR benchmark — phase 0 (2026-10-11)

Comparison between the two candidate engines (spec 7.1) with the same pipeline (spec 7.2): decoding at 16 kHz, FluidAudio VAD (Silero), chunking of speech regions (≤ 28 s), ASR, hallucination filter, FluidAudio offline diarization (pyannote community-1 + VBx), speaker assignment.

## Setup

| | |
|---|---|
| Hardware | MacBook Pro M3 Pro (5P + 6E cores), 36 GB — the spec's reference hardware |
| System | macOS 27.0.1, Xcode 27.0, release build |
| whisper.cpp | 1.9.2 (official xcframework, Metal + flash attention), `large-v3-turbo` model (ggml f16), beam search 5, Italian forced, `no_context` |
| Parakeet | FluidAudio 0.17.7, `parakeet-tdt-0.6b-v3` CoreML (int8 encoder, Neural Engine), language hint `it` |
| Tool | `iago-bench` (`Packages/IAGOTranscription`) |
| Data | 5 real calls of the user recorded from a phone (mono, AAC 44.1 kHz), 2 h 44 min in total. **Not committed**, nor are the transcripts (`test-recordings/`, `bench-out/` ignored) |

| 3 | 34:19 | 102.3 s | 112.2 s | 18.3× | 16.1 s | 25.3 s | 81.5× |
| 4 | 15:37 | 52.2 s | 56.5 s | 16.6× | 7.5 s | 11.9 s | 78.8× |

- Diarization: 2.6–12 s per call (≈ 300× real time); VAD: 0.5–2.8 s.
- Cold load: whisper 8 s (Metal compilation, then cached), Parakeet 77 s at first launch (CoreML compilation, then < 1 s), diarizer 16 s at first launch.
- Both meet "clearly faster than real time" (spec 4.3): a 1-hour call takes ~3 min with whisper, ~40 s with Parakeet.

## Quality (preliminary assessment)

Qualitative assessment by comparing the same passages; there is no hand-transcribed reference, so no WER.

| Aspect | whisper large-v3-turbo | Parakeet v3 |
|---|---|---|
| Colloquial Italian | good | good, similar |
| English terms and product names | better (rendered correctly in most cases) | more phonetic transcription errors |
| Punctuation and segments | regular, short segments (3–8 s) | irregular: some segments up to 20 s long with no punctuation |
| Words at chunk boundaries | rare losses | more often loses the first word of a chunk |
| Hallucinations | few: 5 segments discarded by the filter over 164 min | 3 segments discarded |
| Synthetic voices (`say`, fixtures) | fair | poor |

Diarization (common to both engines): plausible number of speakers (2–5); attribution errors at quick turn changes. To be reassessed with two-track recordings, where diarization concerns only the system track.

Echo filter (fixture with simulated echo −20 dB / +47 ms): with whisper 4 echo segments out of 4 discarded; with Parakeet 2 out of 4, because the two transcripts of the same audio differ too much for the similarity threshold.

## Segmentation by speaker (2026-10-12)

User's assessment: whisper more faithful in the text, Parakeet better on speakers. Cause: same diarization, but only one speaker per whisper segment (segments up to 28 s). Fix: whisper per-word timings, splitting segments at speaker changes (stretches < 1.5 s ignored, cut at the nearby punctuation), then merging truncated sentences from the same speaker.

| Call | Segments before | Segments after | Speed after |
|---|---|---|---|
| 2 (12:29) | 107 | 62 | 17.0× |
| 4 (15:37) | 208 | 92 | 17.0× |
| 3 (34:19) | 390 | 183 | 18.5× |
| 5 (37:08) | 433 | 218 | 16.9× |
| 1 (64:42) | 556 | 309 | 21.7× |

On call 2 the speaker attribution matches Parakeet's for 98% of the time and the speaker changes fall at the same points; the user confirms the improvement. Speed doesn't change.

Per-word timings on a synthetic dialogue with known changes (8 turns, `say` voices): typical error 0–0.2 s with whisper.cpp's heuristic timings, rare errors of ~0.5 s; DTW alignment is not more accurate (constant delay ~0.2 s).

## Decision

Default **whisper.cpp large-v3-turbo** with word-level segmentation by speaker, **Parakeet v3 as the "fast" option** in the settings. See ADR-0023 (accepted).

## How to reproduce

```bash
scripts/download-models.sh whisper-turbo
cd Packages/IAGOTranscription && swift build -c release --product iago-bench && cd ../..
Packages/IAGOTranscription/.build/release/iago-bench --allow-download --out bench-out/real test-recordings/*.m4a
# whisper only, with the current segmentation
Packages/IAGOTranscription/.build/release/iago-bench --engines whisper --out bench-out/real-words test-recordings/*.m4a
```
