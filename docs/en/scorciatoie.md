# Keyboard shortcuts

IAGO lives in the menu bar: many actions start from the **IAGO icon** ![IAGO icon](/icona.svg) at the top right.

## Menu bar icon

| Action | How |
|---|---|
| Open the menu (Start recording, Stop, Discard, Mark moment, Voice note…) | click the icon |
| Start, pause and resume without opening the menu | right-click (or Control-click) the icon |
| Mark moment with a note | in the menu, hold **⌥** on *Mark moment* |

With the menu open:

| Action | Key |
|---|---|
| Open IAGO | **O** |
| Settings | **,** |
| Quit | **Q** |

## In all apps
These also work while you are in Teams or another app; change or turn them off in **Settings › General › Shortcuts in all apps**.

| Action | Shortcut |
|---|---|
| Mark moment | **⌃⌥M** |
| Mark moment with screenshot | **⌃⌥S** |
| Start / Stop recording | **⌃⌥R** |

## Main window

| Action | Shortcut |
|---|---|
| Open or close **Ask IAGO** | **⌘K** |
| Send the question in Ask | **⌘↩** |
| Close the Ask panel | **Esc** |
| Search the archive | click the field at the top right, then `#` for tags and `category:` for categories |
| Expand or collapse a single client in the sidebar (and collapse the others) | **⌥-click** on the client name |

## Notes and windows

With an IAGO window open, the **IAGO**, **Edit** and **Window** menus appear at the top.

| Action | Shortcut |
|---|---|
| Copy, cut, paste, select all | **⌘C**, **⌘X**, **⌘V**, **⌘A** |
| Undo and redo | **⌘Z**, **⇧⌘Z** |
| Paste without formatting | **⌥⇧⌘V** |
| Close the window | **⌘W** |
| Settings | **⌘,** |
| Quit IAGO (asks for confirmation while recording) | **⌘Q** |
| Paste a screenshot or an image into a note | **⇧⌘V** |
| Confirm (Save, Create, Done) | **↩** |
| Cancel or close a dialog | **Esc** |
