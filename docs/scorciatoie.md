# Scorciatoie da tastiera

IAGO vive nella barra dei menu: molte azioni partono dall'**icona di IAGO** ![icona di IAGO](/icona.svg) in alto a destra.

## Icona nella barra dei menu

| Azione | Come |
|---|---|
| Aprire il menu (Avvia registrazione, Stop, Scarta, Segna momento, Nota vocale…) | clic sull'icona |
| Avviare, mettere in pausa e riprendere senza aprire il menu | clic destro (o ctrl-clic) sull'icona |
| Segna momento con nota | nel menu, tieni premuto **⌥** su *Segna momento* |

Con il menu aperto:

| Azione | Tasto |
|---|---|
| Apri IAGO | **O** |
| Impostazioni | **,** |
| Esci | **Q** |

## In tutte le app
Funzionano anche mentre sei in Teams o in un'altra app; si cambiano o disattivano in **Impostazioni › Generale › Scorciatoie in tutte le app**.

| Azione | Scorciatoia |
|---|---|
| Segna momento | **⌃⌥M** |
| Segna momento con screenshot | **⌃⌥S** |
| Avvia / Stop registrazione | **⌃⌥R** |

## Finestra principale

| Azione | Scorciatoia |
|---|---|
| Aprire o chiudere **Chiedi a IAGO** | **⌘K** |
| Inviare la domanda in Chiedi | **⌘↩** |
| Chiudere il pannello di Chiedi | **Esc** |
| Cercare nell'archivio | clic nel campo in alto a destra, poi `#` per i tag e `categoria:` per le categorie |
| Aprire o chiudere un solo cliente nella barra laterale (e chiudere gli altri) | **⌥-clic** sul nome del cliente |

## Note e finestre

Con una finestra di IAGO aperta, in alto compaiono i menu **IAGO**, **Modifica** e **Finestra**.

| Azione | Scorciatoia |
|---|---|
| Copiare, tagliare, incollare, selezionare tutto | **⌘C**, **⌘X**, **⌘V**, **⌘A** |
| Annullare e ripetere | **⌘Z**, **⇧⌘Z** |
| Incollare senza formattazione | **⌥⇧⌘V** |
| Chiudere la finestra | **⌘W** |
| Impostazioni | **⌘,** |
| Uscire da IAGO (con una registrazione in corso chiede conferma) | **⌘Q** |
| Incollare uno screenshot o un'immagine in una nota | **⇧⌘V** |
| Confermare (Salva, Crea, Fatto) | **↩** |
| Annullare o chiudere una finestra di dialogo | **Esc** |
